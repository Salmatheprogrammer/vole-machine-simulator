# Vole Machine Simulator

## Project Description
The Vole Machine Simulator is a C++ application that simulates some simple operations and data transfers in a computer system.
It allows users to load programs, execute instructions, modify registers and memory and display the results on the screen.

## Features
- Load Program
- Run
- Step
- Reset
- Display Memory
- Display Registers
- Modify Memory
- Modify Register
- Print State
- Print Screen

## Project Structure
- Machine: responsible for coordinating the simulation components and managing the basic operations.
- CPU: responsible for executing instructions.
- Memory: responsible for storing data and instructions.
- RegisterFile: responsible for managing the 16 general-purpose registers.
- SimulatorUI: responsible for running the menu , handling user interactions.


## How to Compile and Run
1. Open the project on vs code or any other app
2. Compile the source files using g++.
3. Run the generated executable file.


## How to Use
1. Run the Simulator.
2. Choose an option from the main menu.
3. Load the program.  
4. Choose Run or Step to execute the program.
5. Display or modify memory and registers.
6. Choose Print State to display the PC, IR, and Registers.
7. Choose Print Screen to display the screen output.
